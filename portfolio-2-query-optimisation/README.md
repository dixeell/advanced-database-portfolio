# Portfolio 2: Query Processing and Optimisation

Run `python3 run_portfolio2.py`. It executes five business queries (transcript, CGPA, top-3 per programme using a CTE and `RANK()` window function, failure rate by department, class list), saves results and `EXPLAIN QUERY PLAN` output, then benchmarks four indexing experiments and one rewrite. Read `PERFORMANCE_ANALYSIS.md` for the interpretation. Evidence is in `output/`.
